# Distribuidora J-H S.A.S.

Sitio web corporativo tipo landing page para **Distribuidora J-H S.A.S.**, una empresa real enfocada en la comercialización y distribución de alimentos frescos para negocios, restaurantes, instituciones y comercios.

El proyecto fue desarrollado como una página estática moderna, responsive y orientada a conversión, con secciones claras de presentación empresarial, portafolio de productos, cobertura, proceso de atención y contacto directo por WhatsApp.

## Vista General

La página comunica la propuesta de valor de la distribuidora: frescura, calidad, cumplimiento logístico y atención personalizada. Su diseño busca transmitir confianza comercial mediante una interfaz limpia, navegación simple, llamados a la acción visibles y una experiencia optimizada para dispositivos móviles.

## Características

- Diseño responsive adaptable a escritorio, tablet y móvil.
- Hero principal con mensaje comercial y botones de acción.
- Navegación fija con enlaces a secciones internas.
- Sección institucional con información de la empresa, misión y visión.
- Catálogo visual de productos con tarjetas interactivas.
- Sección de sectores atendidos para reforzar el enfoque B2B e institucional.
- Mapa de cobertura con presencia regional y alcance nacional.
- Formulario de cotización conectado a WhatsApp mediante mensaje prellenado.
- Botones directos de contacto por WhatsApp, llamada y correo.
- Animaciones suaves al hacer scroll.
- Uso de variables CSS para mantener consistencia visual.

## Tecnologías Utilizadas

- **HTML5** para la estructura semántica del sitio.
- **CSS3** para estilos, diseño responsive, animaciones y componentes visuales.
- **JavaScript** para interacciones, navegación activa, animaciones al scroll y envío del formulario a WhatsApp.
- **Font Awesome** para iconografía.
- **Google Fonts** para la tipografía Montserrat.

## Secciones Principales

- **Inicio:** presentación de la marca, propuesta de valor y accesos rápidos.
- **Sobre nosotros:** descripción empresarial, filosofía, misión y visión.
- **Productos:** categorías principales como carnes, embutidos, lácteos y huevos.
- **Sectores atendidos:** instituciones públicas, restaurantes, hoteles, supermercados, tiendas y otros clientes.
- **Cobertura:** presencia regional en Colombia y capacidad de abastecimiento nacional.
- **Contacto:** formulario de cotización y canales directos de comunicación.

## Cómo Visualizar el Proyecto

No requiere instalación de dependencias ni proceso de compilación. Para visualizarlo localmente, abre el archivo `index.html` directamente en el navegador.

También puedes usar una extensión como **Live Server** en Visual Studio Code o Cursor para visualizar los cambios en tiempo real.

## Funcionalidad de Contacto

El formulario de cotización captura los datos del usuario y genera un mensaje prellenado para WhatsApp:

- Nombre
- Empresa
- Teléfono
- Productos de interés

Esto permite que el cliente finalice la solicitud desde WhatsApp sin necesidad de backend, manteniendo el proyecto simple, rápido y fácil de desplegar.

## Objetivo del Proyecto

Este sitio fue creado como una solución web profesional para una empresa distribuidora de alimentos y también forma parte del portafolio del desarrollador. El proyecto prioriza:

- Claridad en la comunicación comercial.
- Experiencia responsive.
- Conversión hacia canales de contacto reales.
